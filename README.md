# Shu — My First Discord Bot

Back in 2021, I wanted to build something that actually *lived* somewhere — something interactive, something that could talk back. So I made **Shu**.

Shu is a simple Discord bot built with `discord.js`. She responds to messages, has a bit of personality, and was the very first thing I pushed to GitHub. If you look at the code, yeah — it's a bunch of `if` statements. And honestly? That's exactly what it should have been at that stage. Every line in here represents the moment things started clicking for me.

She knows who Lil Uzi is. She'll ask to VC with you. She'll react to DIO getting defeated. She's version 1.0.0 and she knows it.

> *Birarenze* — this little bot started something real.

---

## What She Does

- Responds to greetings (`hi`, `Hey`, `Hello!`)
- Has opinions on rap music
- Is fully aware of Jojo's Bizarre Adventure
- Knows what version she's running
- Calls you master (you earned it)

---

## Tech Stack

- **Runtime:** Node.js
- **Library:** discord.js (v11)
- **Entry point:** `index.js`

---

## Running It

```bash
npm install
node index.js
```

> Note: The token in this repo is old and long-since invalidated. If you're forking this for some reason, you'll need your own Discord bot token from the [Discord Developer Portal](https://discord.com/developers/applications).

---

## Why This Exists

This is where it all started. No frameworks, no best practices, just a teenager who figured out how to make a bot say things. Pushing this to GitHub for the first time is one of those moments I won't forget.

Shu was named after a character I liked at the time. She'll probably never get updated. But she'll always be here.
